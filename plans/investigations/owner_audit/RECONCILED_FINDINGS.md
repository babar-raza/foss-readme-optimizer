## Definition of progress

A commit counts toward the quality goal only when it changes a controlling acceptance path and
adds a failing-before/passing-after regression or a sealed run artifact. Diagnostic-only files,
prompt visibility without output lineage, layout-only candidate changes, and no-op over an already
refreshed README do not count as quality closure.

The owner will not claim 30/30 or 33/33 until one committed SHA proves every admitted repository's
declared outcome, all applicable hard gates run and pass, every old content unit and selected fact
has a final disposition, and hosted reruns reproduce accepted artifacts with zero provider calls.
