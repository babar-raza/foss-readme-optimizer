- [master requirements evidence promotion] **2026-08-04 — Fixed promote_finalized_verified_readmes.py: stale finalized READMEs could survive a live acceptance-contract change.** Real bug fix in `scripts/governance/promote_finalized_verified_readmes.py`, the script that copies independently-approved, no-op-proven READMEs into the committed `finalized-repository-readmes-v1/` evidence root. Two compounding defects: (1) `--state-git` defaulted to a hardcoded local snapshot path (`DEFAULT_STATE_GIT = runs/control/local-verified-canary-state.git`) instead of reading the live, authoritative durable state backend, so promotion could run against stale offline state; `_current_states()` now takes an optional `state_git` and falls back to `default_state_backend()` when none is given, and a new `_state_source_record()` records which source was actually used. (2) For "preserved" (previously-promoted) rows, `promote()` only checked whether `source_revision`/`candidate_sha256` were unchanged; it never re-evaluated whether that raw `NO_OP_PROVEN` terminal record still satisfied the *current* acceptance/reuse contract (template hash, reviewer-standard hash, control-plane fingerprint), so a repository could stay listed as finalized even after the presentation contract had since moved past it. Fix: `_validated_entry()` now calls `evaluate_completed_local_poc_cache()` with the live template/reviewer-standard hashes and control-plane fingerprint, and raises a new `StaleAcceptanceError` when `acceptance.reusable` is false; such rows move into a new `promotion_exclusions` list in the manifest with an explicit reason instead of silently staying "promoted." The fix also makes promotion self-healing: it copies durable artifact copies (original README, facts, provenance, plan, patch, claim map, validation, review, verdict, no-op proof, LLM ledger, runtime manifest) beside each README instead of leaving them only in the mutable, gitignored `runs/` tree, verifies existing checksum integrity before writing, and removes stale legacy flat-layout directories. Applying the corrected logic against live state dropped the "finalized" cohort from 10 stale entries down to the 2 that actually still hold current acceptance: Cells and Note Python, each promoted with the complete 14-artifact bundle. Regression test: `tests/unit/test_promote_finalized_verified_readmes.py::test_raw_no_op_is_rejected_when_current_acceptance_contract_is_stale`, plus six other new cases. `RDM-026` moves PLANNED to PARTIAL. Commit `c2a44e036`.
